What a Qute Browser!

tags:#blog #linux #fedora #mac #qutebrowser #minimalism

01. introduction

I've recently gotten into computer minimalism—something I touched on when installing Fedora Asahi Linux Remix on an M1 MacBook Pro 14, which has me living in a tiling window manager and multiple terminal windows daily. I enjoy the aesthetic, and it really suits my style and perspectives on life.

Naturally, I was pleased to find Qutebrowser.

It's a little tricky getting used to keyboard-only browsing at first (though you can still use a mouse for some things if you want or need to). It features Vim keybindings, so if you already know a bit of Vim, you'll feel comfortable right away. While it still takes some practice getting used to hitting i to enter insert mode for typing text, it's going to be tough going back to any browser that doesn't let me hit d to close a tab, o to open a URL or search page, and a plethora of other handy shortcuts.

It's also much easier than one might think to adjust to hitting f and using the resulting hint popups to navigate links across a page or site:

[fig: Navigating with the f command]

Another plus is that it's relatively easy to theme, meaning it fits right into almost any desktop setup or aesthetic:

[fig: Themed Qutebrowser 1]

[fig: Themed Qutebrowser 2]

One drawback to using Qutebrowser is the lack of traditional extension support. That makes using a password manager a bit more work, involving back-and-forth copy/pasting rather than an automatic browser autofill. But honestly, that's just part of the minimalist trade-off, I suppose.
